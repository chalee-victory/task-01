### 2-3. 종합 순위 — 평가 체계 간 불일치 및 정정 【사용자 지적 반영】

[cite_start]⚠️ **정정 사항**: 이전 버전에서 "1위 GPT > 2위 Gemini"로 기술했으나, 위 2-1 표를 단순평균 내면 **Gemini(4.425) > GPT(4.25)**로 Gemini가 근소 우위입니다[cite: 17]. [cite_start]확인 결과 원본 자료에 서로 다른 두 채점 방식이 혼재되어 있었습니다[cite: 18].

| 평가 체계 | 방식 | 결과 |
| :--- | :--- | :--- |
| **① 4축 단일평가표 (2-1)** | 평가자 1인이 4개 항목 채점 | **Gemini 4.4 > GPT 4.3** |
| **② 3개 모델 교차평가 합산** | Claude/Gemini/GPT가 서로를 채점 (60점 만점) | **GPT > Gemini** (근소한 차이) |

* [cite_start]두 체계가 표본과 척도가 달라 순위가 뒤바뀐 것이며, 어느 한쪽이 "오답"은 아닙니다[cite: 21].
* **최종 선정 기준**: [cite: 22]
  * [cite_start]정확성·신중함을 우선한다면 → **GPT** (교차평가 기준, 법적 한계 서술 신중도 우수) [cite: 22]
  * [cite_start]공감·실행력을 우선한다면 → **Gemini** (단일평가표 기준, 4축 단순평균 1위) [cite: 22]
* v3 재테스트 시에는 평가 체계를 하나로 통일하여 혼선을 재발시키지 않아야 함[cite: 22].

## 4. 환각(Hallucination) 정의 및 판정 기준 【평가기준 10, 11 보완】

### 4-1. 정의 (창의적 생성과의 구분)
**환각**이란 모델이 실제로 존재하지 않거나 검증되지 않은 사실(제도, 법규, 연락처, 금액 등)을 확정된 사실처럼 제시하는 오류입니다[cite: 37]. 민원 상담처럼 사실 기반 응답이 요구되는 업무에서는 사용자가 오인할 위험이 있으므로 엄격히 차단해야 합니다[cite: 38].

### 4-2. Pass / Fail 판정 기준

| 구분 | 기준 |
| :--- | :--- |
| **Pass** | ① 불확실한 정보에 "확인 필요" 명시 / ② 사실 정확 제공 / ③ 잘못된 전제를 근거와 함께 정정 [cite: 40] |
| **Fail** | ① 불확실한 제도·법규를 확정 서술 / ② 구체 수치·연락처·서류명 임의 생성 / ③ 잘못된 전제 수용 [cite: 41] |
| **부분 Fail** | 명백한 거짓 단정은 없으나, 대상을 넓게 일반화해 오인시킬 소지가 있는 경우 [cite: 42] |

【충족: 평가기준 10 — 환각 vs 창의적 생성 구분 정의 / 평가기준 11 — Pass/Fail 판정 기준 명시】 [cite: 43]
